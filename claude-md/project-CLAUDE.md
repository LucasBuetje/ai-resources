## What this is

One or two lines: the research question, the deliverable (a paper, a deck, a dataset),
the current stage.

## Layout

- `data/raw/` — source data, **never edit or overwrite**
- `data/clean/` — derived data, regenerated by `code/01_clean.R`
- `code/` — numbered scripts, run in order
- `output/` — figures and tables, all script-generated (never hand-edited)
- `docs/codebook.md` — variable definitions; consult before referencing any variable

## Conventions

- Stata/R/Python: which one, and the version if it matters
- Always recompile the LaTeX doc after editing it; if it fails, fix until it builds
- Build the deck with the `/deck` skill
- Cluster standard errors at the `<unit>` level unless told otherwise
- Open questions / decisions still pending live in `log/current.md`
